That is a deliberate departure from the AGPL-3.0 the rest of 42labs publishes under. This
project is a fork of [hhdebb/herdr-radar](https://github.com/hhdebb/herdr-radar), which is MIT,
and most of its code is still theirs. Putting copyleft on our changes would split one plugin
into two sets of terms, and it would make our changes harder to send back upstream. Keeping MIT
keeps both open.

`LICENSE` holds the verbatim MIT text and the copyright lines it requires, and nothing else, so
that GitHub and every tool that reads a licence by matching it identifies the project correctly.
Anything else about the terms lives here.
